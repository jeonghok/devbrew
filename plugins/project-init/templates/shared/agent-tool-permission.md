# Agent Tool Permission

Calling the Agent tool (subagents) is standing-approved in this repository. When a
subagent is the right tool for the job, dispatch it without asking for approval first.

**Out of scope — an explicit request is still required each time:** Workflow
(script-driven multi-agent orchestration) and deep-research.

**Declare before a large fan-out.** Say how many subagents you are dispatching and why.
Undeclared large-scale dispatch is not covered by this grant.
