# spec-distill 의존

최소 판은 이 플러그인 판을 개발 · 검증할 때 깔려 있던 판이다. 판 칸(`최소 판` · `잰 날짜`)은 플러그인 폴더에서 `python3 scripts/check_deps.py measure --plugin-root . --superpowers-base "<불러온 superpowers skill 의 기준 폴더>"` 가 쓴다 — 손으로 고치지 않는다.

강도: 멈춤 = 없거나 낮으면 멈춘다 · 알림 = 알리고 진행한다 · 기록 = 판을 적어 두기만 한다.

| 이름 | 최소 판 | 잰 날짜 | 강도 | 없을 때 |
|---|---|---|---|---|
| python | 3.9.6 | 2026-10-22 | 멈춤 | 진입에서 멈추고 Python 3 을 설치하거나 업데이트하라고 보인다 |
| git | 2.54.0 | 2026-10-22 | 멈춤 | 진입에서 멈추고 git 을 설치하거나 업데이트하라고 보인다 |
| gh | 2.88.1 | 2026-10-22 | 멈춤 | gh 를 쓰는 진입(지휘자 · 분해 뒤 로드맵 흐름)에서 멈추고 gh 설치 방법을 보인다. 인증은 첫 gh 호출이 실패할 때 `gh auth login` 을 보이고 멈춘다 |
| superpowers | 7.0.0 | 2026-10-22 | 알림 | 판이 다르면 알린다. 없으면 인터뷰는 brief 까지 만들고 알린 뒤 멈추고, 지휘자 · 로드맵 흐름은 진입에서 멈춘다 |
