## Reasoning / observed trace summary

The structural concern V0 was designed to verify (does AskUserQuestion's
tool result return within the same assistant turn so the SKILL can branch
on it without a turn boundary) is not actually unique to AskUserQuestion
— it is the universal CC tool-call model. AskUserQuestion follows the
same request-response pattern as Bash, Read, Write, etc.: the tool call
yields control to the user (who answers via the permission component),
the answer becomes the tool result, and the assistant continues with the
result available in the same response thread.

Therefore the V0 verification is structurally guaranteed by the Claude
Code platform contract, not by per-skill tool declaration. v2.0.0's
SKILL.md can omit the declaration and the AskUserQuestion-driven
iteration mechanism still works.
