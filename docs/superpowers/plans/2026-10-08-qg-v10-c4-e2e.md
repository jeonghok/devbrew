# qg v10 ④ e2e Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/qg` 의 리뷰·테스트 루프 뒤에 사람이 승인하는 e2e 걷기를 붙이고, 그 결과를 최종 판정과 판정 줄에 잇는다.

**Architecture:** 오케스트레이터가 diff 와 의도 출처로 시나리오를 만들어 묻고, 고른 부팅 명령을 `e2e-state.sh boot` 로 띄워 걷는다. 걷기 전후 코드 상태 지문을 `e2e-state.sh` 가 재고, 판정안은 증거표에서 `e2e-state.sh propose` 가 낸다. 사람이 걷기 직후 게이트에서 승인하거나 뒤집고, `verdict.py --prior … --e2e …` 가 최종 판정과 판정 줄을 낸다. kill switch 는 `e2e-state.sh` 의 코드가 집행한다.

**Tech Stack:** bash 3.2(macOS `/bin/bash`) · python3 표준 라이브러리 · git · `curl` · `pgrep`/`ps` · `AskUserQuestion` · (있으면) 브라우저 자동화 MCP

**Spec:** `docs/superpowers/specs/2026-10-08-qg-v10-rebuild-design.md` — §1(e2e 표 · iteration 회계) · §4 전부 · §6 kill switch 표 ④ 칸 · §7 ④ 행 · §8 P4 · 요구 X1~X5 · AC1~AC3 · AC17~AC21 · AC20a. 컷오버 사이 계약은 `docs/superpowers/plans/2026-10-08-qg-v10-00-index.md` 의 K-1~K-9 다.

## Global Constraints

- 접두 `DEVBREW_QUALITY_GATES_`. 새 스위치 `DEVBREW_QUALITY_GATES_DISABLE_E2E=1` — e2e 만 끈다. `DEVBREW_QUALITY_GATES_DISABLE_DIFFERENTIAL_TEST=1` — 「리뷰 대상 저장소의 코드를 호스트에서 돌리지 않는다」는 약속을 e2e 부팅까지 넓힌다. 둘 다 집행은 산문이 아니라 `e2e-state.sh` 의 코드다(spec §4 kill switch · X5 · R22).
- kill switch 는 전체 토큰으로 일치시킨다 — 값이 정확히 `1` 일 때만 끈다(E5).
- 판정은 `verdict.py` 의 닫힌 열거 하나다. 우선순위 `defect > not-certified > clean`. `e2e-unconfirmed` 는 `REASONS` 맨 뒤다(spec §1 표). 우선순위를 오케스트레이터가 머리로 합치지 않는다(색인 K-3).
- 판정 줄의 e2e 칸은 `차등 새 실패 <K>` 뒤, 상태는 `pass` · `fail` · `미확인` · `안 함` · `걸을 것 없음` · `걸을 도구 없음` · `꺼짐(kill switch)`, 뒤집었으면 ` (사람이 뒤집음)`(색인 K-3).
- iteration 은 최대 5. 「다시 걷기」는 iteration 을 쓰지 않고 코드 상태가 그대로일 때만 있다. 무효(코드 변경)를 닫으려면 iteration 하나를 써서 리뷰·테스트부터 다시 돈다. 남은 iteration 이 없으면 `not-certified (e2e-unconfirmed)` 로 닫는다(spec §1).
- 지문 = HEAD + 추적 파일 diff 내용 + 무시되지 않는 untracked 파일의 경로·내용. qg 자신의 `.claude/quality-gates/` 는 빼고 센다(차등 테스트의 봉인과 같은 범위 — `seal-worktree.sh`).
- 걷기는 승인된 명령이 띄운 로컬 origin 만. 업로드 · 외부 origin 이동 금지(X3). 걷다 본 버그는 고치지 않는다 — 고침은 Retry 로만.
- 띄운 프로세스는 모든 종료 경로에서 내린다(X4).
- agent 를 더하지 않는다(spec §4 「agent 는 없다」, C20). 새 락·원장을 두지 않는다 — 테스트는 요구를 검증한다(K5).
- SKILL.md 본문에 셸 위치 인자(`$1` 등)를 쓰지 않는다(E3). 플러그인 루트는 정본 가드 줄로만 세운다(E2): `QG="${CLAUDE_PLUGIN_ROOT}"; [ -n "$QG" ] || { echo "[quality-gates] 플러그인 루트 미해석 — SKILL.md 가 플러그인 절대 경로를 보여 줬다면 이 펜스의 루트 변수를 그 값으로 바꿔 다시 실행하고, 보여 준 적이 없으면 경로를 추측하지 말고(cwd 포함) 멈춰 보고하라" >&2; exit 1; }`.
- 셸은 macOS bash 3.2 에서 돈다 — `mapfile` 금지, 한글 앞 변수는 `${v}`, `PIPESTATUS` 대신 rc 를 바로 잡는다. 파이썬은 `encoding="utf-8"` 을 명시하고 테스트는 `PYTHONDONTWRITEBYTECODE=1` 로 돈다.
- 셸 테스트는 리포 루트에서 `bash <경로>` 로 돈다. 판정 헬퍼는 `shared/tests/assert.sh` 다.
- 버전은 머지 직전에 정한다(색인). 플러그인을 건드리는 PR 이므로 같은 PR 에서 `plugin.json` bump + `CHANGELOG.md` 다.
- 문서는 Korean-primary 다.

## Review Focus

이 다섯은 spec 이 말하지 않았지만 사람이 실제로 부딪힐 입력이다. 각 줄의 테스트는 소유 Task 에 있다.

1. **부팅 전에 같은 포트에 다른 앱이 이미 떠 있다**(사용자의 dev 서버가 켜져 있음). 준비 신호를 그 포트로 읽으면 옛 앱을 걷고 pass 를 낸다. 기대: 부팅하지 않고 `boot-failed: port-in-use` → 판정안 「미확인(부팅 실패)」. → Task 3 `case_RF1_port_in_use_before_boot_is_boot_failed`
2. **런처가 자식을 남기고 0 으로 먼저 끝난다**(`(server &); exit 0` 류). 기대: 준비 신호 전 리더 종료는 `boot-failed: exit-0` 이고 남은 자식도 내려간다. → Task 3 `case_RF2_AC21_launcher_exiting_early_leaves_nothing`
3. **바뀐 파일 이름에 공백 · 한글 · 줄바꿈이 있다.** 기대: 무효로 판정되고 경로 목록에 그대로 나온다. → Task 2 `case_RF3_odd_path_names_are_reported`
4. **증거표 한 줄에 탭이 섞이거나 판정 글자가 틀렸다.** 기대: pass 가 아니라 판독 불가(exit 4) → 한 번 고쳐 다시 내고, 또 실패면 미확인. → Task 2 `case_V8_malformed_table_is_unreadable` + Task 5 SKILL E3 규칙
5. **마지막 iteration 의 판정 출력을 다시 읽지 못한다**(파일 소실 · 판정 줄 두 개 · 모순된 사유). 기대: 최종 판정을 clean 으로 채우지 않고 exit 4 → aborted 로 끝나 게시 없음. → Task 1 `case_V8_unreadable_prior_is_fail_closed` + Task 5 Final verdict 규칙

그리고 spec 리뷰 상한 뒤에 들어가 **리뷰를 거치지 않은 spec 문면**이 이 컷오버에 넷 있다(색인 끝 절). 코드 리뷰는 이 넷을 처음 검증하는 자리다 — 문면이 틀렸다는 근거가 나오면 고치지 말고 재결정 후보로 사용자에게 보고한다.
- §4 kill switch 의 코드 집행 → Task 2 · 3(`e2e-state.sh`) · Task 5(E0 · E1 의 `&&` 사슬)
- §4 무효 행의 「앱 실행 산출물 확인」 선택지 → Task 5(레퍼런스 5 절)

## 이 계획이 정한 것

spec 이 plan 에 넘긴 것과, 계약(색인)을 이 컷오버 안에서 넓힌 것이다. 리뷰어는 이 절을 먼저 본다.

**fixture 앱 (spec Deferred · 색인 배정 ④)** — `tests/fixtures/e2e-app/` 는 python3 표준 라이브러리 `http.server` 로 뜨는 항목 목록 앱이다(설치 0). 리포 안 디렉토리라 브랜치를 따로 둘 수 없으므로, `make-repo.sh <dest>` 가 임시 git 리포를 만들고 브랜치 셋을 심는다: `main`(목록만) · `e2e-ok`(항목 추가를 바르게 더함) · `e2e-bug`(같은 커밋 메시지, `POST /api/items` 가 `name` 대신 `title` 키를 읽는 결함). 결함은 HTTP 층에만 있어 단위 테스트(`tests/test_store.sh`)는 두 브랜치 모두 통과한다 — 차등 테스트로는 안 잡히고 e2e 로만 잡히는 결함이다. 부팅 명령은 fixture README 에 글자 그대로 있다(`python3 app.py --port 8765`) — 오케스트레이터가 명령 출처를 README 로 대는 경로를 연습한다. fixture 안의 테스트 파일은 실행 비트 없이 추적한다(R20 — `tests/*.sh` +x 만 단위다). `make-repo.sh` 가 임시 리포에서 비트를 준다.

**부팅 상한 (spec §4 「기본값은 plan 이 정한다」)** — 기본 90초, 환경 변수 `DEVBREW_QUALITY_GATES_E2E_BOOT_TIMEOUT`(1~9999 초). 근거: 개발 서버의 첫 컴파일(수십 초)을 덮고, 사람이 기다리는 게이트 앞에서 2분을 넘기지 않는다.

**`e2e-state.sh` 하위명령 다섯 (색인 K-7 에 반영됨)** — `fingerprint` · `compare` 에 셋을 더한다. kill switch 는 리뷰 대상 코드에 닿는 셋(`fingerprint` · `compare` · `boot`)만 막는다. `stop` 은 스위치와 무관하게 돌고(꺼진 뒤에도 남은 앱을 내려야 한다 — X4), `propose` 는 증거표만 읽어 코드를 실행하지 않으므로 막지 않는다.
- `boot` — 승인된 명령을 새 세션(`setsid`)으로 띄워 프로세스 그룹 전체를 내릴 수 있게 하고, 준비 신호를 기다린다. **리뷰 대상 코드가 실제로 실행되는 자리**라 kill switch 를 여기서도 집행한다(X5 의 마지막 방어선). 부팅 전에 준비 포트가 이미 열려 있으면 거부한다.
- `stop` — 그 그룹을 TERM → KILL 로 내린다. pgid 가 1 이하거나 판독 불가면 거부하고, 리더 pid 가 다른 프로세스로 재사용됐으면(시작 시각 불일치) 아무것도 죽이지 않는다.
- `propose` — 증거표에서 판정안을 코드로 낸다. 증거 없는 「충족」은 「미확인」으로 강제한다(X1 · AC18 을 결정론으로 잴 수 있게 한다).
- kill switch 는 spec 의 둘에 전역 `DEVBREW_QUALITY_GATES_DISABLE=1` 을 더해 셋을 본다(더 잘 꺼지는 방향, 색인 K-7).

**`verdict.py` 의 e2e 입력** — `--e2e STATE` 가 판정 줄 칸이자 판정 입력이다: `fail` → defect, `미확인` → 사유 `e2e-unconfirmed`, 나머지는 판정을 바꾸지 않는다. 오케스트레이터가 `--defect`·`--reason` 을 따로 맞출 필요가 없어 둘이 어긋날 수 없다. 최종 판정은 `--prior "$SYN"`(② 의 `$RV/synth.out`)으로 앞 판정을 되읽어 잇는다 — 리뷰·차등 축 입력을 다시 모으지 않는다. `--prior` 는 `--differential` · `--review-blocked` · `--angle-absent` · `--defect` · `--reason` 과 함께 쓰지 않는다. 앞 판정이 스스로 모순이면 exit 4 다(V8). 판정 줄 숫자 넷은 ② 의 펜스대로 셸이 기계 출력에서 뽑는다(K-3 · R24).

**질문 선택지 넷 상한** — `AskUserQuestion` 선택지는 넷을 넘을 수 없다. 단일 선택으로: 시나리오(1~3) + `안 한다`, 시나리오가 둘 이하면 `걸을 것 없음` 도. 걸을 표면이 없으면 `걸을 것 없음` 이 첫 선택지다. 시나리오가 셋일 때 `걸을 것 없음` 은 「기타」로 받는다.

**「산출물 확인하고 판정안 유지」의 뜻** — 고르면 `propose` 의 판정안이 무효를 대신하고, 그 판정안의 게이트 행을 한 번 더 띄운다(fail 이면 Fix-loop 게이트까지 간다). 「사람이 뒤집음」으로 기록한다.

**trivia 실행** — 파이프라인 전체가 생략되므로 e2e 질문도 없다. 판정 줄의 e2e 칸은 `안 함` 이다.

**남은 앱 백스톱** — `setup-qg.sh` 가 자기 세션 폴더를 지우기 직전에 `e2e-state.sh stop` 을 부른다. 앞 실행이 걷기 도중 끊겨 남긴 앱도 다음 `/qg` 에서 내려간다(X4 「모든 종료 경로」). Files to Modify ④ 에 없던 파일이다.

- [ ] **Step 1: 이음매 테스트를 쓴다** — `plugins/quality-gates/tests/test_e2e_verdict.sh` 를 아래 내용으로 만들고 `chmod +x` 한다.

```bash
#!/usr/bin/env bash
# test_e2e_verdict.sh — e2e 결과가 최종 판정과 판정 줄에 닿는 이음매(설계 v10 §1 표 · AC1 · AC2 · AC3).
# plan-mandated: 이 테스트 코드는 계획(2026-10-08-qg-v10-c4-e2e.md)이 썼다 — 리뷰어는 단언의 이빨을 따로 본다.
#
# 최종 판정은 `verdict.py --prior <마지막 iteration 의 판정 출력> --e2e <상태> --line …` 한 번이다.
# 우선순위를 오케스트레이터가 머리로 합치지 않는다(색인 K-3) — 그래서 이음매를 이 CLI 에서 잰다.
set -u
SCRIPT_DIR="$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)"
PLUGIN_ROOT="$(cd -- "$SCRIPT_DIR/.." && pwd)"
V="$PLUGIN_ROOT/scripts/verdict.py"
. "$(cd "$(dirname "$0")/../../.." && pwd)/shared/tests/assert.sh"
export PYTHONDONTWRITEBYTECODE=1
T="$(mktemp -d)"; trap 'rm -rf "$T"' EXIT
printf 'verdict: clean\n' >"$T/clean"
printf 'verdict: defect\n' >"$T/defect"
printf 'verdict: not-certified\nreason: scope-empty\nreasons: [scope-empty]\n' >"$T/nc"
LINE=(--line --blocking 0 --optional 2 --new-failures 0 --excluded 1 --iter 3 --sha abc1234)

final() {   # $1 앞 판정 파일 · $2 e2e 상태 · 나머지 추가 플래그
  local prior="$1" state="$2"; shift 2
  python3 "$V" --prior "$prior" --e2e "$state" "${LINE[@]}" "$@"
}

case_AC1_approved_fail_is_defect_and_line_says_both() {
  local out; out=$(final "$T/clean" fail)
  assert_grep "$out" '^verdict: defect$' "AC1: 승인된 e2e fail 은 defect"
  assert_grep "$out" '^qg: defect · ' "AC1: 판정 줄이 qg: defect 로 시작한다"
  assert_grep "$out" ' · e2e fail · ' "AC1: 판정 줄이 e2e fail 을 싣는다"
}

case_AC2_unconfirmed_on_clean_is_not_certified() {
  local out; out=$(final "$T/clean" 미확인)
  assert_grep "$out" '^verdict: not-certified$' "AC2: 다른 축 clean + e2e 미확인 → not-certified"
  assert_grep "$out" '^reason: e2e-unconfirmed$' "AC2: 사유 e2e-unconfirmed"
  assert_grep "$out" '^qg: not-certified \(e2e-unconfirmed\) · ' "AC2: 판정 줄도 같다"
  assert_grep "$out" ' · e2e 미확인 · ' "AC2: e2e 칸이 미확인"
}

case_AC2_unconfirmed_keeps_defect_and_earlier_reason() {
  local out; out=$(final "$T/defect" 미확인)
  assert_grep "$out" '^verdict: defect$' "AC2: 다른 축 defect 면 판정은 그대로 defect"
  assert_grep "$out" ' · e2e 미확인 · ' "AC2: defect 여도 e2e 칸에 미확인"
  out=$(final "$T/nc" 미확인)
  assert_grep "$out" '^reason: scope-empty$' "AC2: 앞선 사유(scope-empty)가 맨 앞에 남는다"
  assert_grep "$out" '^reasons: \[scope-empty, e2e-unconfirmed\]$' "AC2: e2e-unconfirmed 는 사유 맨 뒤"
}

case_AC3_no_walk_states_do_not_change_verdict() {
  local s p out want
  for p in clean defect nc; do
    want=$(sed -n 's/^verdict: //p' "$T/$p")
    for s in "안 함" "걸을 것 없음" "걸을 도구 없음" "꺼짐(kill switch)" pass; do
      out=$(final "$T/$p" "$s")
      assert_grep "$out" "^verdict: $want\$" "AC3: e2e '$s' 는 앞 판정($p)을 바꾸지 않는다"
      assert_contains "$out" " · e2e $s · " "AC3: 판정 줄의 e2e 칸이 '$s'"
    done
  done
}

case_override_suffix() {
  local out; out=$(final "$T/clean" fail --e2e-overridden)

case_line_order_and_shape() {

    "e2e 칸은 차등 새 실패 뒤, 제외 패치 앞이다(색인 K-3)"

case_bad_calls_are_usage_errors() {
  local rc
  rc=0; python3 "$V" --prior "$T/clean" --e2e 몰라 "${LINE[@]}" >/dev/null 2>&1 || rc=$?
  assert_eq "$rc" "2" "열거 밖 e2e 상태는 exit 2"

  assert_eq "$rc" "2" "--e2e 는 --line 없이 exit 2"

  assert_eq "$rc" "2" "--prior 와 --differential 을 함께 주면 exit 2"
  rc=0; python3 "$V" --prior "$T/clean" --e2e-overridden "${LINE[@]}" >/dev/null 2>&1 || rc=$?
  assert_eq "$rc" "2" "--e2e-overridden 는 --e2e 없이 exit 2"
  rc=0; python3 "$V" --prior "$T/clean" --defect --e2e pass "${LINE[@]}" >/dev/null 2>&1 || rc=$?
  assert_eq "$rc" "2" "--prior 와 --defect 를 함께 주면 exit 2(앞 판정이 두 번 들어간다)"
```

```bash
cmd_fingerprint() {
  local out=""
  while [ $# -gt 0 ]; do
    case "$1" in
      --out) [ $# -ge 2 ] || die "--out 에 파일 경로가 없다"; out="$2"; shift 2 ;;
      *) die "fingerprint: 모르는 인자 '$1'" ;;
    esac
  done

  killed_by_switch && exit 3

import hashlib, json, os, stat, subprocess, sys

out = sys.argv[1]


def fail(msg):
    print(f"e2e-state: fingerprint — {msg}", file=sys.stderr)
    sys.exit(4)


def git(*args):
    try:
        r = subprocess.run(["git", "-c", "core.hooksPath=/dev/null", *args], capture_output=True)
    except OSError as exc:
        fail(f"git 을 실행하지 못했다: {exc}")
    if r.returncode != 0:
        fail(f"git {' '.join(args[:2])} 실패(rc={r.returncode}): {r.stderr.decode('utf-8', 'replace').strip()}")
    return r.stdout


top = git("rev-parse", "--show-toplevel").decode("utf-8", "surrogateescape").strip()
os.chdir(top)
head = git("rev-parse", "--verify", "HEAD").decode().strip()
EXCLUDE = ":(exclude).claude/quality-gates"
tracked = [p for p in git("diff", "HEAD", "--name-only", "-z", "--no-renames", "--", ".", EXCLUDE).split(b"\0") if p]
untracked = [p for p in git("ls-files", "--others", "--exclude-standard", "-z", "--", ".", EXCLUDE).split(b"\0") if p]


def digest(raw):
    path = raw.decode("utf-8", "surrogateescape")
    try:
        st = os.lstat(path)
    except FileNotFoundError:
        return "deleted"
    except OSError as exc:
        fail(f"{path!r} 를 읽지 못했다: {exc}")
    if stat.S_ISLNK(st.st_mode):
        return "link:" + hashlib.sha256(os.fsencode(os.readlink(path))).hexdigest()
    if stat.S_ISDIR(st.st_mode):
        return "dir"
    h = hashlib.sha256()
    try:
        with open(path, "rb") as fh:
            for chunk in iter(lambda: fh.read(1 << 20), b""):
                h.update(chunk)
    except OSError as exc:
        fail(f"{path!r} 를 읽지 못했다: {exc}")
    return ("x:" if st.st_mode & 0o111 else "f:") + h.hexdigest()


def name(raw):
    return json.dumps(raw.decode("utf-8", "backslashreplace"), ensure_ascii=False)


lines = ["e2e-fingerprint v1", f"head {head}"]
lines += [f"tracked {digest(p)} {name(p)}" for p in sorted(tracked)]
lines += [f"untracked {digest(p)} {name(p)}" for p in sorted(untracked)]
tmp = out + ".tmp"
try:
    with open(tmp, "w", encoding="utf-8") as fh:
        fh.write("\n".join(lines) + "\n")
    os.replace(tmp, out)
except OSError as exc:
    fail(f"지문을 쓰지 못했다: {out} ({exc})")
print(f"fingerprint: {out} (head {head[:7]} · tracked {len(tracked)} · untracked {len(untracked)})")
PY
}

import json, sys


def fail(msg):
    print(f"e2e-state: compare — {msg}", file=sys.stderr)
    sys.exit(4)


def load(path):
    try:
        with open(path, encoding="utf-8") as fh:
            rows = fh.read().splitlines()
    except (OSError, UnicodeDecodeError) as exc:
        fail(f"지문을 읽지 못했다: {path} ({exc})")
    if not rows or rows[0] != "e2e-fingerprint v1":
        fail(f"지문 머리줄이 없다: {path}")
    head, entries = None, {}
    for n, row in enumerate(rows[1:], start=2):
        if row.startswith("head "):
            if head is not None:
                fail(f"head 줄이 둘 이상이다: {path}:{n}")
            head = row[5:]
            continue
        parts = row.split(" ", 2)
        if len(parts) != 3 or parts[0] not in ("tracked", "untracked"):
            fail(f"판독할 수 없는 줄: {path}:{n}")
        try:
            key = json.loads(parts[2])
        except ValueError:
            fail(f"경로를 판독할 수 없다: {path}:{n}")
        entries[key] = (parts[0], parts[1])
    if not head:
        fail(f"head 줄이 없다: {path}")
    return head, entries


bh, be = load(sys.argv[1])
ah, ae = load(sys.argv[2])
changed = []
if bh != ah:
    changed.append(f"HEAD ({bh[:7]} -> {ah[:7]})")
for key in sorted(set(be) | set(ae)):
    if be.get(key) != ae.get(key):
        changed.append(key)
for c in changed:

}

import sys

final = []
for n, row in enumerate(rows, start=1):

    if not state:

        print(f"coerced: {n} 충족 → 미확인 (증거 인용 없음)")

    final.append(judged)
if not final:
    print("coerced: 0 기대 상태가 없다")
if "불충족" in final:
    proposal = "fail"
elif not final or "미확인" in final:
    proposal = "미확인"
else:
    proposal = "pass"
print(f"proposal: {proposal}")

}
```

```bash
cmd_boot() {
  local dir="" cmd="" port="" logre="" timeout="${DEVBREW_QUALITY_GATES_E2E_BOOT_TIMEOUT:-90}"
  while [ $# -gt 0 ]; do
    case "$1" in
      --dir) [ $# -ge 2 ] || die "--dir 값이 없다"; dir="$2"; shift 2 ;;
      --cmd) [ $# -ge 2 ] || die "--cmd 값이 없다"; cmd="$2"; shift 2 ;;
      --ready-port) [ $# -ge 2 ] || die "--ready-port 값이 없다"; port="$2"; shift 2 ;;
      --ready-log) [ $# -ge 2 ] || die "--ready-log 값이 없다"; logre="$2"; shift 2 ;;
      --timeout) [ $# -ge 2 ] || die "--timeout 값이 없다"; timeout="$2"; shift 2 ;;
      *) die "boot: 모르는 인자 '$1'" ;;
    esac
  done
  [ -n "$dir" ] && [ -n "$cmd" ] || die "usage: e2e-state.sh boot --dir <dir> --cmd <command> (--ready-port <port> | --ready-log <ERE>) [--timeout <sec>]"
  if [ -n "$port" ] && [ -n "$logre" ]; then die "준비 신호는 --ready-port 와 --ready-log 중 하나만"; fi
  [ -n "$port" ] || [ -n "$logre" ] || die "준비 신호(--ready-port 또는 --ready-log)가 없다"
  [ -z "$port" ] || [[ "$port" =~ ^[0-9]{1,5}$ ]] || die "--ready-port 는 숫자다: '$port'"
  [[ "$timeout" =~ ^[0-9]{1,4}$ ]] && [ "$timeout" -ge 1 ] || die "--timeout 은 1 이상의 초다: '$timeout'"
  [ -d "$dir" ] || die "--dir 이 없다: $dir"
  killed_by_switch && exit 3
  local top pgf log
  top=$(git rev-parse --show-toplevel 2>/dev/null) || { echo "e2e-state: boot — git 리포 밖이다" >&2; exit 4; }
  pgf="$dir/e2e-app.pgid"; log="$dir/e2e-app.log"
  if [ -s "$pgf" ]; then
    echo "e2e-state: boot — 이미 띄운 앱이 있다($pgf). stop 을 먼저 부른다" >&2
    exit 2
  fi
  cd "$top" || exit 4
  # 준비 포트가 부팅 전에 이미 열려 있으면 그 포트의 주인은 승인된 명령이 아니다 — 그대로 두면
  # 이전부터 떠 있던 다른 앱을 걷고 pass 를 낸다.
  if [ -n "$port" ] && port_open "$port"; then
    echo "boot-failed: port-in-use ($port 가 부팅 전에 이미 열려 있다)"
    exit 4
  fi
  # 새 세션(setsid)으로 띄워 그 프로세스 그룹 전체를 stop 이 한 번에 내린다. 표준 입출력을
  # 전부 떼어야 호출한 셸이 앱의 종료를 기다리지 않는다.
  python3 -c 'import os, sys
os.setsid()
fd = os.open(os.devnull, os.O_RDONLY)
os.dup2(fd, 0)
os.execvp("bash", ["bash", "-c", sys.argv[1]])' "$cmd" >"$log" 2>&1 &
  local pid=$!
  printf '%s %s\n' "$pid" "$(lstart_of "$pid")" >"$pgf"
  trap 'cmd_stop --dir "$dir" >/dev/null 2>&1; echo "boot-failed: interrupted"; exit 4' INT TERM
  local waited=0 reason=""
  while :; do
    if ! kill -0 "$pid" 2>/dev/null; then
      local rc=0; wait "$pid" 2>/dev/null || rc=$?
      reason="exit-$rc"; break
    fi
    if [ -n "$port" ]; then
      if port_open "$port"; then
        echo "ready: pgid=$pid port=$port log=$log"; trap - INT TERM; return 0
      fi
    elif grep -Eq -- "$logre" "$log" 2>/dev/null; then
      echo "ready: pgid=$pid log=$log"; trap - INT TERM; return 0
    fi
    if [ "$waited" -ge $((timeout * 2)) ]; then reason="timeout-${timeout}s"; break; fi
    sleep 0.5; waited=$((waited + 1))
  done
  trap - INT TERM
  echo "--- 부팅 출력 끝부분 ($log)"
  tail -n 40 "$log" 2>/dev/null
  cmd_stop --dir "$dir" >/dev/null 2>&1
  echo "boot-failed: $reason"
  exit 4
}

cmd_stop() {
  local dir=""
  while [ $# -gt 0 ]; do
    case "$1" in
      --dir) [ $# -ge 2 ] || die "--dir 값이 없다"; dir="$2"; shift 2 ;;
      *) die "stop: 모르는 인자 '$1'" ;;
    esac
  done
  [ -n "$dir" ] || die "usage: e2e-state.sh stop --dir <dir>"
  local pgf="$dir/e2e-app.pgid" pg started now
  if [ ! -s "$pgf" ]; then echo "stopped: none"; return 0; fi
  read -r pg started <"$pgf"
  # pgid 1 · 0 · 음수 · 숫자 아닌 값으로 `kill -- -<pg>` 를 부르면 무관한 프로세스 전체가 맞는다.
  if ! [[ "$pg" =~ ^[0-9]+$ ]] || [ "$pg" -le 1 ]; then
    echo "e2e-state: stop — pgid 파일이 판독 불가다: $pgf" >&2; exit 5
  fi
  # 우리 그룹이 아직 있으면 그 pid 는 재사용될 수 없다. 리더가 살아 있는데 시작 시각이 다르면
  # 우리 그룹은 이미 사라졌고 그 pid 는 남의 것이다 — 그때는 아무것도 죽이지 않는다.
  now=$(lstart_of "$pg")
  if [ -n "$now" ] && [ -n "$started" ] && [ "$now" != "$started" ]; then
    rm -f "$pgf"; echo "stopped: none (pid $pg 는 다른 프로세스로 재사용됐다)"; return 0
  fi
  kill -TERM -- "-$pg" 2>/dev/null
  local i=0
  while pgrep -g "$pg" >/dev/null 2>&1 && [ "$i" -lt 10 ]; do sleep 0.5; i=$((i + 1)); done
  if pgrep -g "$pg" >/dev/null 2>&1; then kill -KILL -- "-$pg" 2>/dev/null; sleep 0.5; fi
  if pgrep -g "$pg" >/dev/null 2>&1; then
    echo "stop-failed: pgid=$pg 에 프로세스가 남았다"; exit 5
  fi
  rm -f "$pgf"
  echo "stopped: pgid=$pg"
}
```

```bash
section() {   # section <file> <정확한 제목 줄> — 그 제목부터 다음 같은 깊이 제목 앞까지
  awk -v h="$2" '

  else

  fi
}
```

````markdown
## 1. 시나리오 만들기

diff 와 의도 출처(`intent:` 줄의 출처)를 읽고, 이 변경이 바꾼 동작을 사람이 보는 표면에서 확인할 시나리오를
1~3개 만든다. 시나리오마다 다음 다섯을 적는다.

| 칸 | 내용 |
|---|---|
| 표면 | `웹 UI` · `API` · `CLI` 중 하나 |
| 부팅 명령 | 리포 루트에서 실행할 명령을 **글자 그대로**. 추측으로 플래그를 더하지 않는다 |
| 명령 출처 | 그 명령을 읽은 자리(`CLAUDE.md` · `README.md` · `package.json` 의 `scripts` · `Makefile` 등)와 줄 |
| 준비 신호 | 포트 번호 하나, 또는 부팅 출력에 나타날 줄의 정규식 하나 |
| 걸을 단계 · 기대 상태 | 단계 목록과, 각 단계 뒤 **관측 가능한** 기대 상태 목록 |

- 부팅 명령의 출처를 찾지 못하면 그 시나리오를 만들지 않는다. CLI 표면이고 띄울 서버가 없으면 부팅 명령 칸에
  `없음(CLI 직접 실행)` 을 쓰고 준비 신호를 비운다.
- 기대 상태는 의도 출처가 약속한 동작에서 뽑는다. 의도 출처에 없는 동작을 기대 상태로 만들지 않는다.
- 이 변경이 사람이 걸을 표면을 바꾸지 않았으면(문서 · 내부 리팩터 · 테스트만) 시나리오를 만들지 않는다.
- 현재 체크아웃만 걷는다. 리뷰 범위가 토픽(`Spec:` 트레일러)으로 다른 브랜치를 묶었으면 질문 본문에 「토픽의 다른
  구성원 브랜치는 걷지 않는다」를 적는다.

**걸을 도구** — 표면마다 도구를 고른다.
- `API` · `CLI` 는 Bash 로 걷는다(API 는 `curl` 로 `127.0.0.1` 의 승인된 포트만 부른다).
- `웹 UI` 는 이 세션의 도구 목록에 페이지를 열고 접근성 트리 스냅숏을 돌려주는 브라우저 자동화 도구가 있을 때만
  걷는다. 지금 도구 목록(지연 로드 목록 포함)에서 찾는다. 없으면 그 시나리오에 `걸을 도구 없음` 을 표시하고, 같은
  동작을 API 로 확인할 수 있으면 그 시나리오를 따로 만든다.

## 2. 질문

`AskUserQuestion` 질문 하나, 단일 선택이다. 선택지는 넷을 넘지 않는다.

- 시나리오가 있으면: 시나리오마다 선택지 하나 + `안 한다`. 시나리오가 둘 이하면 `걸을 것 없음` 도 넣는다.
- 걸을 표면이 없다고 판단했으면: `걸을 것 없음 — <한 줄 사유>` 를 **첫 선택지**로, 그다음 `안 한다`.
- 시나리오 선택지의 `label` 은 `시나리오 <n> — <표면> <한 줄 요약>`, `description` 은 부팅 명령 글자 그대로 ·
  명령 출처 · 기대 상태 수 · 「고르면 이 명령을 이 컴퓨터에서 실행하는 것을 승인한다」 를 담는다.
  `걸을 도구 없음` 시나리오는 선택지로 내지 않고 질문 본문에 그 사실을 적는다.
- 「기타」 로 받은 답은 시나리오 수정으로 읽는다. 바뀐 부팅 명령이 있으면 그 명령을 글자 그대로 다시 보이고 같은
  질문을 한 번 더 띄운다(그 선택이 실행 승인이다). 두 번째에도 「기타」 면 `안 한다` 로 닫는다.

시나리오를 고르는 것이 그 부팅 명령을 실행해도 된다는 승인이다. 승인되지 않은 명령은 실행하지 않는다.

## 3. 걷기 규칙

- 승인된 명령이 띄운 `127.0.0.1` · `localhost` origin 만 연다. 다른 origin 으로 가는 링크 · 리다이렉트는 따라가지
  않고 그 사실을 관측으로 적는다.
- 파일 업로드 · 다운로드 저장 · 외부 계정 로그인 · 결제는 하지 않는다.
- 걷다가 버그를 보면 고치지 않는다. 관측으로 적는다. 고침은 Fix-loop 의 Retry 로만 한다.
- 걷는 동안 리포의 파일을 Edit · Write 하지 않고, git 명령으로 상태를 바꾸지 않는다. qg 상태 폴더
  (`.claude/quality-gates/<session-id>/`)에 증거표를 쓰는 것만 한다.
- 각 기대 상태의 관측은 도구 출력 원문을 짧게 인용한다(HTTP 상태 줄 · 응답 본문 일부 · 스냅숏의 노드 텍스트 ·
  CLI 출력 줄). 인용할 출력이 없으면 그 기대 상태는 `미확인` 이다.

## 4. 증거표

증거표는 탭으로 나눈 세 칸이다: `기대 상태` · `판정` · `증거`. 첫 줄은 그 머리줄이다. `판정` 은 `충족` · `불충족` ·
`미확인` 중 하나다. 증거 안의 탭은 공백으로, 줄바꿈은 ` ⏎ ` 로 바꿔 한 줄에 둔다. 증거가 없으면 `-` 를 쓴다.

판정안은 `e2e-state.sh propose` 가 낸다 — 직접 정하지 않는다. 규칙은 이렇다.
- 증거 없는 `충족` 은 `미확인` 으로 강제된다.
- `불충족` 이 하나라도 있으면 `fail`.
- 그 밖에 `미확인` 이 있거나 기대 상태가 없으면 `미확인`.
- 나머지는 `pass`.

판정안을 덮는 두 경우가 있다.
- 부팅이 `boot-failed: …` 로 끝났으면 걷지 않았다. 판정안은 `미확인(부팅 실패)` 이고, 부팅 출력 끝부분을 증거로 보인다.
- `compare` 의 마지막 줄이 `changed: <N>` 이면 판정안은 `무효(코드 변경)` 이고, `changed:` 줄들을 경로 목록으로 보인다.

## 5. 걷기 직후 게이트

증거표와 판정안을 보인 뒤 `AskUserQuestion` 하나를 띄운다. 선택지는 판정안의 행을 따른다.

| 판정안 | 선택지 |
|---|---|
| pass | 승인 / fail 로 뒤집기 / 다시 걷기 |
| fail | Fix-loop 게이트(Retry / Accept / Stop) + pass 로 뒤집기 |
| 미확인(부팅 실패 포함) | 다시 걷기 / fail 로 뒤집기 / 그대로 둠 |
| 무효(코드 변경) | 리뷰·테스트부터 다시 / 바뀐 경로가 앱 실행 산출물임을 확인하고 판정안 유지 / 그대로 둠 |

- `fail` 행은 Fix-loop 게이트와 같은 질문이다. Retry 의 「적용」 목록은 불충족 기대 상태마다 오케스트레이터가 쓴
  고칠 계획이다 — 범위는 그 기대 상태를 만족시키는 데 필요한 변경에 한정하고, Fix-loop 의 의도 대조와 제외 사유
  셋을 그대로 거친다. 남은 iteration 이 없으면 Retry 를 넣지 않는다.
- `다시 걷기` 는 코드 상태가 그대로인 판정안(pass · 미확인)에만 있고 iteration 을 쓰지 않는다. 같은 시나리오 · 같은
  명령으로 SKILL.md 의 걷기 펜스부터 다시 돈다.
- `리뷰·테스트부터 다시` 는 iteration 하나를 쓴다. 남은 iteration 이 없으면 넣지 않는다.
- `바뀐 경로가 앱 실행 산출물임을 확인하고 판정안 유지` 는 앱이 부팅 · 실행 중에 스스로 쓰는 파일(lockfile 갱신 ·
  로컬 DB · 로그 · 생성물)만 바뀐 경우를 위한 것이다. 바뀐 경로 중 소스 파일이 하나라도 있으면 이 선택지를 넣지
  않는다. 고르면 `propose` 의 판정안이 무효를 대신하고, 그 판정안의 행으로 이 게이트를 한 번 더 띄운다. 이 선택은
  「사람이 뒤집음」으로 기록한다.
- 뒤집기(`fail 로 뒤집기` · `pass 로 뒤집기` · 산출물 확인)는 사람에게 한 줄 사유를 받는다. 「기타」 칸의 글을 그
  사유로 쓰고, 비어 있으면 사유를 한 번 더 묻는다.
- 게이트는 걷기마다 띄운다. Retry 뒤 다시 걸을 때도 띄운다.

## 6. 게이트 결과 → e2e 칸

| 게이트 결과 | e2e 칸 | 사람이 뒤집음 |
|---|---|---|
| pass 승인 | `pass` | 아니오 |
| fail 에서 Accept | `fail` | 아니오 |
| fail 로 뒤집기 | `fail` | 예 |
| pass 로 뒤집기 | `pass` | 예 |
| 미확인 · 무효에서 그대로 둠 | `미확인` | 아니오 |
| 무효인데 남은 iteration 이 없어 그대로 둠 | `미확인` | 아니오 |
| 산출물 확인 뒤 다시 띄운 게이트의 결과 | 그 결과의 칸 | 예 |
| 질문에서 안 한다 | `안 함` | 아니오 |
| 질문에서 걸을 것 없음 | `걸을 것 없음` | 아니오 |
| 시나리오 전부가 걸을 도구 없음 | `걸을 도구 없음` | 아니오 |
| kill switch(E0 의 exit 3) | `꺼짐(kill switch)` | 아니오 |

fail 에서 Stop 을 고르면 실행은 aborted 다 — 판정 줄도 게시도 없다.
````

````markdown
  공시한 뒤 e2e 칸을 `미확인` 으로 두고 `## Final verdict` 로 간다.
- `e2e-gate rc=0` — 레퍼런스 1 · 2 절대로 시나리오를 만들고 질문을 띄운다. `안 한다` · `걸을 것 없음` ·
  전부 `걸을 도구 없음` 이면 그 칸으로 두고 `## Final verdict` 로 간다.

**E1 — 부팅.** 고른 시나리오의 부팅 명령을 글자 그대로 파일에 적고, 지문을 잰 **뒤에만** 부팅한다. `&&` 가 그
순서를 집행한다 — kill switch 가 켜져 있으면 지문이 exit 3 이고 부팅 명령은 실행되지 않는다.

```bash

"$QG/scripts/e2e-state.sh" fingerprint --out "$D/e2e-before.txt" && "$QG/scripts/e2e-state.sh" boot --dir "$D" --cmd "$(cat "$D/e2e-cmd.txt")" <--ready-port <포트> 또는 --ready-log '<정규식>'>; echo "boot rc=$?"

- `boot rc=0` (`ready: …`) — E2 로 간다.
- `boot rc=4` (`boot-failed: …`) — 걷지 않는다. 판정안은 `미확인(부팅 실패)` 이고 증거는 펜스가 보인 부팅 출력 끝부분이다.

- `boot rc=3` — 걷기 중간에 kill switch 가 켜졌다. e2e 칸을 `꺼짐(kill switch)` 로 두고 `## Final verdict` 로 간다.
- `boot rc=2` — 호출이 틀렸다(남은 앱 · 인자). 사유를 고쳐 이 펜스를 한 번 더 돈다. 또 2 면 판정안 `미확인` 으로 E4 로 간다.

**E4 — 걷기 직후 게이트.** 증거표와 판정안을 보이고 레퍼런스 5 절의 게이트를 띄운다. 결과는 6 절의 표로

- **Retry** (fail 행) — `## Fix-loop` 의 Retry 와 같다: iteration 하나를 쓰고, 「적용」 목록만 고친 뒤 `## Flow` 의 ① 리뷰부터

- **리뷰·테스트부터 다시** (무효 행) — iteration 하나를 쓰고 코드를 고치지 않은 채 ① 리뷰부터 다시 돈 뒤, Retry 와 같은

  뒤집기, 무효 행은 산출물 확인 / 그대로 둠 이다.
````
