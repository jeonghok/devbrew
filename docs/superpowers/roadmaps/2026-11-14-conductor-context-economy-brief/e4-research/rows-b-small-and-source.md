- `job new` 를 부르는 절차 · skill(b15): `git grep "job new"`(references · skills · templates), E2 브랜치 `conducting*.md`.
- 다시 보내기 전에 결과 파일을 커밋하는 절차(b11): `team-files.md` §9, E2 브랜치 `conducting-team.md`.

- 역할 문서 틀과 devbrew 사본의 바이트 같음 락(b19): `git grep "roadmaps/leader\|role-leader"`(tests · shared/tests).
- brief 를 옮기는 자동 이전(b20): `legacy_names.py` · `repo_defaults.py` 의 옛 의도 폴더 처리. 옛 폴더는 읽기 전용으로만 쓰인다.
